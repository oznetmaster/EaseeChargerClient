# EaseeChargerClient

Independent C# client for the Easee charger REST API and real-time SignalR updates, targeting .NET 10 and .NET Framework 4.7.2.

- [Getting started and Windows applications](../README.md)
- [Client API reference](api/EaseeChargerClient.yml)
- [Windows hosting API reference](api/EaseeChargerClient.Hosting.yml)
- [Changelog](../CHANGELOG.md) and [release notes](../RELEASE-NOTES.md)
- [XML documentation standard](../DOCUMENTATION.md)
- [Publication setup](../PUBLISHING.md)

The reference includes 168 non-deprecated REST operations from the checked-in Easee specification. Available account permissions determine which operations a caller may execute. Position observations use a nullable upstream model whose Easee wire compatibility remains unverified.
